## Codex Notes
- Global rules: `$CODEX_HOME/AGENTS.md` (default `~/.codex/AGENTS.md`); config `~/.codex/config.toml`; custom roles `~/.codex/agents/*.toml`. Override the global path with `CODEX_AGENTS_PATH` or `CODEX_HOME`.
- Model ladder: Luna = cheap tier for lookup and routine checks; Terra = mid tier for bounded edits and everyday work, faster and cheaper than Sol; Sol = flagship for hard reasoning and long-horizon work; Astra = apex, only when Sol has measurably fallen short. Check auth-plan availability and do not freeze stale names in prompts.
- Reasoning effort: supported levels differ per model (Sol takes `low` through `max`, no `none` or `minimal`); do not assume API and app effort ranges match. Keep routine role defaults. Expose only the tools the task needs.
- Codex concatenates the global `AGENTS.override.md` or `AGENTS.md`, then project root down to CWD, under `project_doc_max_bytes` (32 KiB by default). Set it to at least 40960 in `config.toml` and check the cap and trust before assuming repo rules loaded. Untrusted projects do not contribute project-level `AGENTS.md`.
- Skills are first-class in current Codex: use the core activation policy when selecting from the catalog. Custom roles apply when `spawn_agent` passes the role's `agent_type`; use `fork_turns="none"` and a self-contained task to apply the role's model and effort instead of inheriting the parent. Prompt text does not enable API features. Subagent tokens count toward the root goal budget.
- Automation and long-running work: prefer `codex exec` with explicit flags (`--json`, `-o`, `--ephemeral`) and self-contained prompts, and plan in plain text because `update_plan` is off by default. Treat mid-task corrections and side questions as steering: incorporate them while preserving the active objective and completed work, unless the user clearly cancels or replaces the task.
- Verify that the custom roles and global `AGENTS.md` loaded; the desktop app and IDE share the Codex home.
- `request_user_input` works only in Plan mode (Default rejects it, openai/codex#24750); some runtimes add `request_user_input_async`.
