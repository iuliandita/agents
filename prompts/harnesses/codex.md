## Codex Notes
- Global rules: `$CODEX_HOME/AGENTS.md` (default `~/.codex/AGENTS.md`); config `~/.codex/config.toml`; custom roles `~/.codex/agents/*.toml`. Override the global path with `CODEX_AGENTS_PATH` or `CODEX_HOME`.
- Model ladder: GPT-6 Luna = cheap tier for lookup and routine checks; GPT-6.1 Sol = balanced and flagship, split by effort (`medium` default for routine work, higher for hard reasoning and long-horizon work); GPT-6 Astra = apex at 5x the Sol price, only when Sol has measurably fallen short. Verify exact model IDs and auth-plan availability before scripting; do not freeze stale names in prompts.
- Reasoning effort: supported levels differ per model (Sol takes `low` through `max`, no `none` or `minimal`); do not assume API and app effort ranges match, and verify the selected model's settings before scripting. Keep routine role defaults; evaluate apex for difficult planning and review. Expose only the tools the task needs.
- Codex discovers `AGENTS.md` in a stable chain: `$CODEX_HOME/AGENTS.override.md` or `AGENTS.md` (global, default `~/.codex/`), then project root down to CWD, concatenated under a byte cap (`project_doc_max_bytes`, 32 KiB default; 40 KiB recommended), so keep the global file lean. Untrusted projects do not contribute project-level `AGENTS.md`, so check trust before assuming repo rules loaded.
- Skills are first-class in current Codex: use the core activation policy when selecting from the catalog. Custom roles in `~/.codex/agents/*.toml` apply when `spawn_agent` passes the role's `agent_type`; use `fork_turns="none"` and a self-contained task to apply the role's model and effort instead of inheriting the parent. Prompt text does not enable API features. Subagent tokens count toward the root goal budget.
- Automation and long-running work: prefer `codex exec` with explicit flags (`--json`, `-o`, `--ephemeral`) and self-contained prompts, and plan in plain text because `update_plan` is off by default. Verify current CLI/docs before setting automation flags. Treat mid-task corrections and side questions as steering: incorporate them while preserving the active objective and completed work, unless the user clearly cancels or replaces the task.
- Verify discovery after deploy: list the custom roles and confirm the global `AGENTS.md` loaded; the desktop app and IDE share the same Codex home, so no separate deploy is needed.
