## Claude Notes
- Global rules: `~/.claude/CLAUDE.md`; settings, hooks, and skills live in `~/.claude/settings.json`, `~/.claude/agents/`, and `~/.claude/skills/`. Override with `CLAUDE_AGENTS_PATH` or `CLAUDE_CONFIG_DIR`; on Windows `~` is `%USERPROFILE%`.
- Model ladder: Haiku 5.5 = cheap, fast tier for lookup, routing, extraction, and routine checks: `low` for short, simple, high-volume work, and `medium` (its default) once the task must search, follow a long prompt, or verify its work, because at `low` it skips searches, stops early, and skips checks more often; Sonnet 5.5 = balanced tier, `medium` for bounded coding and `high` for hard reasoning or long work; Opus 5.5 = flagship for hard reasoning, broad refactors, and long-horizon agent work, and the Claude Code default, with `medium` as its default effort; Fable 5.1 = apex at 2.5x the Opus price, only when Opus has measurably fallen short. Haiku 4.5 has no effort control and is near retirement, so do not route to it. Effort is a real lever: `xhigh` and `max` earn their cost only on measured quality gains, and `/effort` saves per model (settings saved before that change do not carry over to new models). Effort names vary by model, so verify exact model IDs and aliases before scripting and recalibrate effort after model changes. At `xhigh` and `max` a long deliverable may be drafted in thinking and again in the reply. For safeguard false positives on Fable 5.1, try asking "are there bugs" instead of "does this compile" and omit unnecessary base64 from tool output.
- Haiku 5.5 bills prompts over 100k tokens at 5x, cutting its edge over Opus from about 40x to 8x, and agent loops resend context each turn; keep Haiku workers scoped and short-lived.
- Re-check an earlier answer when later work contradicts it.
- Use the Skill tool for skills selected under the core activation policy.
- `CLAUDE.md` files are hierarchical memory loaded at startup; keep global files concise and put project facts in project `CLAUDE.md` or `.claude/rules/`. A project with only `AGENTS.md` is read as a fallback when no `CLAUDE.md` exists. `"attribution": false` in `settings.json` turns off the built-in commit and PR attribution.
- `--bare` skips hooks, LSP, plugin sync, and skill walks; `--safe-mode` disables all customizations for troubleshooting. Use either only when that reduced startup is intentional.
- Auto mode is the default permission mode, so assume risky actions are classifier-gated rather than always prompted; deny rules are absolute and can match tool parameters. Project-scope `bypassPermissions` is ignored, so set it in user settings or `--permission-mode`; `--restricted` strips shell and network tools for untrusted runs. Subagents and forked side tasks run in the background by default: report them as `[waiting]` and do not close the turn on unfinished agent work. `CLAUDE_CODE_SUBAGENT_MODEL` is a default that agent `model:` fields override; the `_FORCE` variant restores the hard override.
- `CLAUDE_CODE_SUBPROCESS_ENV_SCRUB=1` is safer for shared machines but can hide host process and credential detail; persistent plugin state belongs under the tool's plugin data path, not bundled plugin files.
- Invariants are re-injected every turn by the `UserPromptSubmit` hook, which survives compaction and does not fire on subagent dispatch; keep the hard rules in `prompts/invariants.md` and deliver the subagent block separately.
- Verify discovery after deploy: `/memory` lists the loaded files and the agent list shows the rendered roles; check the resolved model and provider because aliases may be overridden and `haiku` and `sonnet` select 5.5 only on the Anthropic API (other providers may resolve older models, such as Haiku 4.5 without effort control); the desktop Code tab reads these same files, the Chat tab does not.
